KeyValuePurgeOptions

data class KeyValuePurgeOptions(val deleteMarkersThreshold: Duration = 30.minutes, val noThreshold: Boolean = false)(source)

Configures KeyValueBucket.purgeDeletes.

  • When noThreshold is true, all delete and purge markers are removed regardless of age.

  • Otherwise deleteMarkersThreshold controls the cutoff; markers older than the threshold are removed entirely while markers within the window have their history truncated but the marker itself is retained. Defaults to 30 minutes, matching the Go and Java clients.
