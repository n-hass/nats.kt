KeyValueBucket

interface KeyValueBucket : AutoCloseable(source)

A handle to a Key-Value bucket. Use this to perform client operations against a bucket.

Implementations hold a persistent request subscription, so callers must call close when finished — or use AutoCloseable.use to scope the lifetime.
